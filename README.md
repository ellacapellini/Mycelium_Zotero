# 🍄 Mycelium

*My library, kept safe.*

Most of what I know is underground: a tangle of papers, books and half-read PDFs, quietly passing notes to each other. This is that network, backed up where the daylight can reach it.

**How it grows:** Zotero is the soil. Every morning a small GitHub Action wakes up (around 05:00 UTC), pulls the library, and commits it here. I don't do anything. It just spreads.

| File | What it is |
|---|---|
| `library.json` | The whole library, folders and tags included. This is what my [website](https://ellacapellini.github.io) reads. |
| `library.bib` | The same thing, for people who cite for a living. |
| `fetch_zotero.py` | The bit that does the fetching. |

**Status:** 🌱 seeding → 🌿 building → 🌲 evergreen. It is never finished, and I'd like to keep it that way.

*Nothing in here is peer-reviewed by me. Some of it isn't even read yet.*
